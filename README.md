## About
Personal portfolio of Faizan Khan: production RAG AI agents (n8n, Pinecone, OpenAI, LangChain, Azure AI Foundry), LLM apps and full stack projects. Plain HTML, CSS and JavaScript, no build step.

## Features
- Animated hero with a Python agent console that "runs" on load (Run button replays it)
- Flowing data-line background, count-up stats, scrolling tools strip
- Filterable Skills and Projects, experience timeline, certifications
- Contact form that sends to WhatsApp or email, plus a floating WhatsApp button
- Downloadable resume, dark / light theme, fully responsive and accessible

## Structure
```
Faizan-Portfolio/
├── index.html
├── style.css
├── script.js            # CONFIG (phone, email, links) is at the top
└── assets/
    ├── Faizan_Khan_Resume.pdf
    └── img/faizan.webp  # add your photo here (a monogram shows until then)
```

## Customize
- Contact details and project links: `CONFIG` at the top of `script.js`
- Photo: save a square image as `assets/img/faizan.webp`
- Resume: replace `assets/Faizan_Khan_Resume.pdf`
- Colors and fonts: CSS variables at the top of `style.css`

## Run locally
```bash
python -m http.server 5500
# open http://localhost:5500
```

## Deploy (GitHub Pages)
```bash
git add .
git commit -m "Update portfolio"
git push
```
Then **Settings → Pages → Deploy from a branch → main / (root)**.
